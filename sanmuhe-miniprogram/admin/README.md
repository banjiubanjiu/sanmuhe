# 三木合经营后台

这是无需构建的 CloudBase 静态后台，入口是 `admin/index.html`。

当前后台已覆盖参考图里的主要经营板块：

- 首页：读取真实订单、预约、报名、茶室和活动数据生成经营概览。
- 茶室预约：读取 `reservations`，支持确认、取消和管理备注。
- 茶事活动：读取 `event_signups`，支持确认、取消，并同步活动报名人数。
- 订单管理：读取 `orders`，支持标记发货、完成自提、取消待支付订单。
- 用户管理：从订单、预约、报名聚合真实用户画像，不单独伪造会员档案。
- 商品管理：通过 `manageCatalog` 维护茶叶、茶饮、茶室、活动资料。
- 内容管理：维护 `content_blocks`，首页轮播会被小程序首页读取。
- 数据统计：基于有效订单、预约和报名生成销售趋势、品类销售额和排行。
- 营销中心：维护 `coupons` 和 `marketing_campaigns` 基础数据。
- 设置管理：维护 `store_settings` 门店基础信息和运营开关。

上线前需要完成：

- 在 CloudBase 身份认证中启用用户名密码登录，并创建管理员账号。
- 将管理员加入云函数环境变量白名单：优先配置 `ADMIN_UIDS`，也可配置 `ADMIN_USERNAMES`；小程序内部测试账号继续用 `ADMIN_OPENIDS`。
- 将后台访问域名加入 CloudBase 安全域名。
- 部署 `manageCatalog`、`manageOperations`、支付相关云函数后，再把 `admin/` 上传到静态托管。

图片上传保存的是 CloudBase Storage `cloud://` 文件 ID，适合小程序端直接读取；如果要在后台网页中显示私有桶图片，可后续增加临时链接换取逻辑。

当前仍需运营侧补齐的真实可用条件：

- 微信支付必须配置商户号、API v3 密钥、商户证书、回调 URL 和 HTTP 回调函数访问权限。
- 优惠券目前是后台数据和会员中心可用券数量，尚未实现领取、核销和订单抵扣闭环。
- 会员等级、积分规则和消息通知只保存配置，不自动计算权益或主动发送订阅消息。
