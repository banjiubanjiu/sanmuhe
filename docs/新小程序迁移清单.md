## 你需要在微信 / 云控制台完成

### 1. 微信开发者工具

1. 打开目录：`sanmuhe/sanmuhe-miniprogram`  
2. 确认右上角 AppID 为 `wx47e7cc7143682291`  
3. 云开发面板选择环境 `cloudbase-d2gq023qn50e9d82f`  
4. **上传并部署全部云函数**（含 `memberCenter`，注意带上 `config.json`）  
5. 真机预览（手机号能力需真机）

### 2. 写入你的新 openid（必做）

1. 调用 `getOpenId` 云函数获取你的 openid  
2. 复制返回的 openid  
3. 在云开发控制台 → 云函数 → 环境变量，把下面函数的变量设为你的 openid（多个用英文逗号）：

| 变量 | 用到的函数 |
| --- | --- |
| `ADMIN_OPENIDS` | manageCatalog, manageOperations, createOrder, createReservation, serviceNotify, memberCenter |
| `STAFF_OPENIDS` | 同上 |
| `MEMBER_TEST_OPENIDS` | memberCenter（模拟充值白名单） |
| `WECOM_ORDER_WEBHOOK` | createOrder, createPayment, wechatPayNotify（订单/支付企业微信群机器人） |
| `WECOM_RESERVATION_WEBHOOK` | createReservation（茶室预约企业微信群机器人；未配置时回退到 `WECOM_ORDER_WEBHOOK`） |
| `WECOM_MENTIONED_MOBILES` | createOrder, createReservation（企微通知 @ 手机号列表） |

也可改 `cloudbaserc.json` 后再用 CLI 部署。

### 3. 管理后台 Publishable Key

1. [CloudBase 控制台](https://tcb.cloud.tencent.com/) → 环境 `cloudbase-d2gq023qn50e9d82f`  
2. 登录授权 / 安全配置 → 创建 **Publishable Key（可发布密钥）**  
3. 粘贴到 `admin-src/src/App.vue` 的 `CONFIG.accessKey`  
4. 执行：

```bash
cd sanmuhe-miniprogram
npm run admin:build
```

5. 将 `admin/` 部署到该环境的静态托管（若使用）
