## 静态托管操作命令

```bash
# 环境 ID（本仓库 root cloudbaserc.json 已配置，可省略 --env-id）
ENV=cloudbase-d2gq023qn50e9d82f

# 1) 构建经营后台（产物输出到 admin-panel/admin/）
cd sanmuhe-miniprogram && npm run admin:build

# 2) 部署到静态托管根路径
tcb hosting deploy ../admin-panel/admin / --env-id $ENV

# 3) 查看托管文件 / 网站信息
tcb hosting list --env-id $ENV
tcb hosting detail --env-id $ENV
```

> ⚠️ 部署后旧的 hash 版 `assets/index-*.js/css` 会残留，属孤儿文件，可按需清理：
> `tcb hosting delete <文件路径> --env-id $ENV --yes`；目录用 `--dir`。
