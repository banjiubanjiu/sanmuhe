设计确认（相对现状 / v1 / v2）

  • 你说得对：充值档位常驻页面既占空间又像第二张卡；点「充值」再弹层选金额，是钱包/会员类产品的常见做法，也更干净。
  • 视觉：回退到现有代码的精致路线（hero 底图 + 渐变遮罩 + 宋体/砂金），不另起一套「糙」风格。
  • 结构变化只有一处核心：删除常驻 wallet-card；余额/积分收到会员卡底部；充值流程进底部 sheet。
  • 未开通：保留现有「开通表单」质感，但不再挂一整块储值钱包预览卡。
  • 协议/说明：仍放在开通勾选与弹层副文案，不铺满首屏。
