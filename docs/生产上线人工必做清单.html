禾熙生产上线人工必做清单

以下事项需要真实主体、真实资质或微信公众平台人工操作，代码无法代替。

1. 完善用户隐私保护指引

  • 入口：微信公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引。
  • 如实填写：联系人、手机号、收货地址、订单信息、预约/报名备注、OpenID/用户标识。
  • 填写开发者联系方式，用于用户申请查询、更正、删除个人信息。

2. 完成小程序备案

  • 准备主体证件、负责人证件、负责人手机号、补充材料。
  • 平台初审后注意工信部 12381 短信核验，通常需 24 小时内完成。
  • 备案成功后再进入正式提审发布。

3. 确认经营资质

  • 营业执照。
  • 按实际售卖范围准备食品经营许可证、食品生产许可证或预包装食品销售备案凭证。
  • 确认茶饮、茶叶、活动/课程类目与小程序服务类目一致。

4. 配置微信支付

  • 开通微信支付商户号，准备 API v3 密钥、商户证书、私钥、平台证书/公钥。
  • 配置支付回调 HTTPS 域名，并把支付环境变量填到云函数。
  • 用小额真机订单验证支付、回调、库存释放、优惠券核销。

5. 配置订阅消息模板

  • 在微信公众平台申请模板：订单支付、订单发货、预约状态、活动报名状态。
  • 把模板 ID 填入后台「设置管理」。
  • 真机确认用户授权后能收到服务通知。

6. 提审前最终检查

  • 真机跑通：首页、购物车、支付、预约、活动报名、我的页面。
  • 后台确认：订单履约、预约确认、活动确认、用户数据删除。
  • 在项目目录执行 npm run admin:verify，确认后台构建、云函数语法、静态资源和包体忽略规则通过。
  • 开发者工具预览包体保持低于 2MB。
