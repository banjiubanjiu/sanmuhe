# 禾煦小程序 · 服务类目选择与资质材料

更新时间：2026-07-31  
适用：自建微信小程序（堂饮点单、茶叶商城、茶室预约、活动、会员），**商家自营、非多商户平台**。

> **重要：** 类目名称与上传材料以微信公众平台 **添加服务类目时页面提示为准**，会随政策调整。本文是对照官方开放类目说明与常见茶馆/餐饮自营实践的整理，**不是法律意见**。  
> 官方类目表：https://developers.weixin.qq.com/miniprogram/product/material/

---

## 1. 先分清：备案 vs 许可证

| 名称 | 是什么 | 禾煦自营茶馆小程序 |
| --- | --- | --- |
| **小程序 / ICP 备案** | 向工信部报备「有这个服务」 | **需要**（正式上线前） |
| **ICP 许可证** | 经营性互联网信息服务许可 | **通常不需要**（自营、非有偿信息平台） |
| **EDI 许可证** | 在线数据处理与交易处理（多商户平台类） | **通常不需要**（非电商平台/多商家入驻） |

很多人把「备案」说成「要办 ICP 证」。自营店难的是 **执照 + 食品/餐饮相关证 + 类目 + 备案 + 支付**，不是人人先办增值电信许可证。

个体户一般也**办不了** ICP/EDI 许可证；若强制人人要这两证，个体小店都开不了——实际自营路径不靠这两证。

## 2. 主体要求

| 要求 | 说明 |
| --- | --- |
| 必须是 **非个人主体** | 企业 **或 个体工商户** |
| 个人主体 | 基本做不了电商卖茶 + 支付类业务 |
| 一致性 | 小程序主体、营业执照、微信支付商户尽量同一主体 |

## 3. 微信小商店是什么（和本文的关系）

**微信小商店** ≈ 微信官方「免开发卖货小程序模板」，标准电商店，不是禾煦这种自建茶馆小程序。

| | 微信小商店 | 禾煦自建小程序 |
| --- | --- | --- |
| 开发 | 基本免开发 | 自研、可定制堂饮/桌号/预约等 |
| 定位 | 快速卖货 | 门店场景 + 私域经营 |
| 资质 | 仍要类目与食品等证 | 本文按**服务类目**准备 |

卖茶仍要食品相关资质；小商店**不是**「不用证」。产品策略会变，部分入口可能不再支持新注册小商店，以当前后台为准。

## 4. 建议选择的服务类目

小程序可挂 **多个服务类目**（数量上限以后台为准）。原则：**页面上有什么能力，就挂什么类目。**

### 4.1 推荐组合（完整业务）

| 优先级 | 业务 | 建议类目方向 | 说明 |
| --- | --- | --- | --- |
| **必选 A** | 茶叶在线售卖（自提/快递） | **商家自营 → 食品饮料** | 官方适用范围含食品、饮料、**茶叶** 等在线销售及配送 |
| **必选 B** | 堂饮点单、到店消费 | **餐饮 → 餐饮服务场所/餐饮服务管理企业**（三级选最接近茶饮/综合餐饮的，如咖啡厅等，以可选列表为准） | 适用于餐饮场所点餐、外卖、门店管理等 |
| **建议 C** | 茶室预约 | **生活服务 / 休闲娱乐** 下与「到店预约、休闲」最接近的一项 | 以后台实际可选名为准 |
| **视情况 D** | 活动报名（尤其收费） | 生活服务或票务/活动相关 | 纯展示压力小；收费更应对齐类目 |
| **不要选** | 多商户入驻 | **电商平台** | 自营不要选；平台类还可能牵扯 EDI 等 |

### 4.2 分阶段上线（证不全时）

| 阶段 | 开放功能 | 类目 | 材料压力 |
| --- | --- | --- | --- |
| 1 | 堂饮 + 预约 | 餐饮 + 生活服务侧 | 执照 + 餐饮相关食品证 |
| 2 | 再开茶叶商城 | 加上 **商家自营-食品饮料** | 补齐卖茶对应证 |

页面上**先不卖茶**，就先不要挂食品饮料电商类目，审核更干净。

### 4.3 不要和「小店商品类目·茗茶」搞混

- **服务类目**：整个小程序能提供什么服务（公众平台申请）——本文重点  
- **小店/商品类目**：微信小店商品侧更细，与自建小程序服务类目不是同一套表

## 5. 需要准备的材料

### 5.1 通用（几乎都要）

| 材料 | 说明 |
| --- | --- |
| **营业执照** | 清晰扫描件/照片；经营范围尽量覆盖茶/食品/餐饮相关 |
| **法人或经营者身份证** | 按后台要求 |
| **小程序备案** | 正式发布前完成 |
| **微信认证**（若未认证） | 企业/个体认证 |

### 5.2 商家自营 · 食品饮料（卖茶）

官方常见要求（**4 选 1**）：

1. 《**食品经营许可证**》，或  
2. 《**食品生产许可证**》（自产自销），或  
3. 仅销售预包装食品时的《**预包装食品销售备案凭证**》，或  
4. 口岸商店《国境口岸卫生许可证》（一般不适用）

**注意：**

- 证上项目需覆盖实际销售（如预包装食品、茶叶等）  
- 卖酒需另选酒类类目；保健品勿乱挂保健品类目  

### 5.3 餐饮 · 餐饮服务场所（堂饮点单）

官方常见要求（**3 选 1**）：

1. 《**食品经营许可证**》，或  
2. 平台+门店声明类材料 + 门店《食品经营许可证》（多店/管理型场景），或  
3. 口岸相关许可（特殊场景）

**单店茶馆：** 多数为 **营业执照 + 食品经营许可证**（经营范围含餐饮制售等相关项目，以证为准）。

### 5.4 茶室预约 / 活动

- 生活服务类类目有的仅需执照，有的另有要求——**以点选时弹窗为准**  
- 活动仅展示、不收费时压力通常更小  

### 5.5 会员储值（单独注意）

- **不是**靠多挂一个服务类目就解决  
- 预付卡/储值可能涉及商务部门 **单用途预付卡备案** 等（各地执行不一）  
- 与食品类目分开规划；充值上线前单独做合规确认  

### 5.6 自营一般不需要

| 材料 | 自营茶馆 |
| --- | --- |
| ICP **许可证** | 通常不要 |
| EDI **许可证** | 通常不要（非多商户交易平台） |

## 6. 功能与类目、材料对照

| 功能 | 类目覆盖 | 材料重点 |
| --- | --- | --- |
| 堂饮点单 / 桌号 | 餐饮 · 餐饮服务场所… | 食品经营许可（餐饮相关） |
| 茶叶商城（自提/快递） | 商家自营 · 食品饮料 | 食品经营 **或** 预包装备案等 |
| 茶室预约 | 生活服务/休闲向 | 多为执照，看后台 |
| 活动报名 | 视是否收费 | 轻则执照 |
| 会员充值 | 功能合规另议 | 不单靠类目 |
| 微信支付 | 商户号 + 主体一致 | 不是服务类目材料 |

## 7. 操作路径

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 对应小程序  
2. **设置** → **基本设置 / 服务类目**（或信息设置中的服务类目）  
3. 添加类目 → 搜索「食品饮料」「餐饮」等  
4. 按提示上传证照 → 等待审核  
5. 类目通过后再提审代码；**类目与页面功能保持一致**  

说明：每月修改次数有限，尽量一次选准。

## 9. 一句话结论

- **类目：** 卖茶 → **商家自营-食品饮料**；堂饮 → **餐饮-餐饮服务场所…**；预约 → **生活服务/休闲** 中合适一项。  
- **材料：** 执照 + **食品相关证（卖茶 4 选 1 / 堂饮侧常见食品经营许可）** + **备案**；自营一般 **不要** ICP/EDI 许可证。  
- **最终以公众平台提交页提示为准。**
